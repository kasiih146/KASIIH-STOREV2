⚠️ Firebase belum disetup

Admin panel ini perlukan Firebase (percuma) supaya perubahan anda live untuk semua pelawat. Buka fail firebase-config.js dan ikut arahan di dalamnya, atau lihat README.md untuk panduan penuh:

  1. Buat project di console.firebase.google.com
  2. Aktifkan Firestore Database
  3. Aktifkan Authentication → Email/Password, tambah satu user (email + password anda)
  4. Copy firebaseConfig dari Project Settings → tampal dalam firebase-config.js
  5. Refresh page ini
